## Learning Objectives
By the end of this lesson, you will be able to:
- Explain why comparing different asset types requires translating them into a shared basis for comparison
- Identify risk-adjusted return as one common framework used to make such comparisons
- Explain why skipping this translation step leads to poor investment decisions

## Core Content

Lesson 8 established that different assets need different valuation frameworks. Here's the "why" this creates a genuine challenge when an investor needs to actually choose between different types of assets, not just evaluate them individually: if a stock is analyzed one way and gold another, how does an investor meaningfully compare the two to decide how to allocate capital between them?

[VERIFIED FACT] This is generally addressed by translating different assets onto some shared basis for comparison, rather than comparing their native, asset-specific metrics directly. **Risk-adjusted return** — considering not just an investment's expected return, but its return relative to the risk taken to achieve it — is one common such framework, allowing a comparison across very different asset types on a more equivalent footing than comparing raw returns alone.

This is why concluding "Asset A had a higher return than Asset B, so Asset A was the better investment" can be misleading without considering the different risk levels involved — a comparison ignoring risk-adjustment skips exactly the translation step this lesson describes, and can lead to systematically favoring riskier assets simply because higher risk sometimes, though not always, correlates with higher raw returns, echoing Lesson 1's foundational risk-return relationship.

## Worked Example

[ILLUSTRATIVE EXAMPLE] An investor compares two investments over the same period: one delivered a higher raw return but with significantly more volatility and uncertainty along the way; the other delivered a somewhat lower raw return but with much more stability and predictability. [ASSUMPTION] Comparing raw returns alone would favor the first investment, but a risk-adjusted comparison — considering how much risk was taken on to achieve each return — might reveal the second investment actually delivered a more favorable risk-adjusted outcome, a meaningfully different conclusion than the raw-return comparison alone would suggest.

## Practice Quiz

1. Why does comparing different asset types require translating them into some shared basis for comparison?
2. What is risk-adjusted return, and why is it used for this kind of comparison?
3. Why can comparing raw returns alone, without risk adjustment, be misleading?

## Answer Key

1. Because different assets are evaluated using different native frameworks (Lesson 8), so a direct, apples-to-apples comparison requires some common basis that applies across asset types.
2. A framework considering an investment's return relative to the risk taken to achieve it, used because it allows a more equivalent comparison across very different asset types than comparing raw returns alone.
3. Because it can systematically favor riskier assets simply because they sometimes produce higher raw returns, without accounting for the additional risk taken on to achieve that return.

## Answers and Explanations

1. This directly extends Lesson 8's concept to the practical challenge of comparing across asset types.
2. This introduces the specific common framework the lesson focuses on.
3. This is the central caution, connecting back to Lesson 1's risk-return relationship.

## Key Takeaways
- Comparing different asset types meaningfully requires translating them onto some shared basis, since each uses its own native valuation framework.
- Risk-adjusted return is one common framework used to make such comparisons more equivalent.
- Comparing raw returns alone, without risk adjustment, can be misleading and favor riskier assets without full justification.
