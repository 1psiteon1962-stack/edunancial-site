## Learning Objectives
By the end of this lesson, you will be able to:
- Explain the basic principle behind an A/B test

## Core Content

**A/B testing** generally compares two versions of something — an ad, a webpage, an email subject line — to see which performs better, by showing each version to a comparable group and measuring the results. Here's the "why" this is genuinely a scientific method applied to marketing: a valid test requires isolating a single variable, changing only one thing between version A and version B, so that any difference in outcome can be confidently attributed to that specific change, rather than to some other, uncontrolled difference between the two groups.

Here's the risk of skipping this discipline: if a business changes multiple elements at once — a new headline, a new image, and a new call-to-action button, all in the same test — and version B performs better, there's no way to know which specific change actually caused the improvement, or whether one change helped while another hurt, with the net effect only coincidentally positive. A confident conclusion drawn from this kind of test is closer to an anecdote than actual evidence.

Before treating any A/B test result as a genuine finding, what exactly was the single variable that changed, and was the sample size and testing period actually large enough to distinguish a real effect from random variation?

## Worked Example

[ILLUSTRATIVE EXAMPLE] A marketing team runs a test changing an ad's headline, image, and button color simultaneously, and the new version performs better. [ASSUMPTION] The team concludes the new headline was the winning factor and rolls it out everywhere — but since three variables changed at once, they actually have no reliable way to know whether the headline, the image, or the button color drove the improvement, or whether one of those changes was actually hurting performance while another was helping even more, an ambiguity a properly isolated single-variable test would have avoided entirely.

## Practice Quiz

1. What is the basic principle behind an A/B test?
2. Why is isolating a single variable essential to drawing a valid conclusion?
3. What happens if multiple variables are changed at once and the result improves?

## Answer Key

1. Comparing two versions of something, shown to comparable groups, to see which performs better.
2. Because it's the only way to confidently attribute any difference in outcome to that specific change, rather than to an uncontrolled, confounding difference.
3. There's no reliable way to know which specific change caused the improvement, or whether one change helped while another hurt, with the net effect only coincidentally positive.

## Key Takeaways
- A/B testing works by comparing two versions to see which performs better under otherwise comparable conditions.
- A valid test requires isolating a single variable to confidently attribute any difference to that specific change.
- Changing multiple variables at once produces a result that's an anecdote, not reliable evidence, even if the outcome looks positive.
