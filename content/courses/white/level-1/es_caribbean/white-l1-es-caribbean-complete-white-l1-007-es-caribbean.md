# WHITE-L1-007: Órdenes de Mercado vs. Órdenes Límite

## Objetivos de Aprendizaje
1. Definir una orden de mercado y una orden límite.
2. Explicar el intercambio entre certeza de ejecución y control de precio.
3. Identificar un escenario donde cada tipo de orden es apropiado.

## Contenido Principal
Una **orden de mercado** compra o vende un valor inmediatamente al mejor precio disponible en ese momento — priorizando la velocidad de ejecución sobre el precio exacto. Una **orden límite** establece un precio específico al cual el inversionista está dispuesto a comprar o vender — priorizando el control de precio, pero la ejecución no está garantizada si el mercado nunca alcanza ese precio.

## Ejemplo Práctico
*EJEMPLO ILUSTRATIVO:* Una acción se está negociando alrededor de $50. Noah coloca una orden de mercado para comprar — se ejecuta casi instantáneamente, pero en un mercado que se mueve rápido podría pagar un poco más o menos de $50 dependiendo del momento exacto de ejecución. Su amiga Devi en cambio coloca una orden límite para comprar a $48 — ella no pagará más de $48, pero si el precio nunca baja a $48, su orden simplemente nunca se ejecuta.

## Quiz Práctico
1. ¿Qué prioriza una orden de mercado?
2. ¿Qué prioriza una orden límite?
3. Verdadero/Falso: Una orden límite garantiza la ejecución.
4. ¿Qué tipo de orden usarías si conseguir que la transacción se haga inmediatamente importa más que el precio exacto?

## Clave de Respuestas
1. Velocidad de ejecución   2. Control de precio   3. Falso   4. Una orden de mercado

## Respuestas y Explicaciones
1. Las órdenes de mercado se ejecutan al mejor precio actual disponible, priorizando la velocidad.
2. Las órdenes límite se ejecutan solo al precio especificado o mejor, priorizando el control.
3. Las órdenes límite se ejecutan solo si el mercado alcanza el precio establecido — no está garantizado.
4. Las órdenes de mercado son adecuadas para situaciones donde la ejecución inmediata importa más.

## Puntos Clave para Recordar
- Las órdenes de mercado priorizan la velocidad; las órdenes límite priorizan el control de precio.
- Las órdenes límite no están garantizadas a ejecutarse si no se alcanza el precio objetivo.
- Elige según si la velocidad o la precisión del precio importa más para esa transacción.
