# WHITE-L1-038 : L'Inflation et Son Effet sur les Placements

## Objectifs d'Apprentissage
1. Définir l'inflation en termes généraux.
2. Expliquer pourquoi l'inflation érode le pouvoir d'achat.
3. Identifier pourquoi « battre l'inflation » importe pour le placement à long terme.

## Contenu Principal
L'inflation est la hausse générale des prix dans le temps, ce qui réduit le pouvoir d'achat d'un montant d'argent donné. *FAIT VÉRIFIÉ :* Si le rendement d'un placement ne dépasse pas le taux d'inflation, le pouvoir d'achat réel (ajusté pour l'inflation) de l'investisseur peut diminuer même si le solde de son compte croît nominalement.

## Exemple Pratique
*EXEMPLE ILLUSTRATIF :* Un placement rapporte 3 % par année pendant que l'inflation court à 4 % cette année-là. Le solde du compte croît nominalement, mais son pouvoir d'achat réel diminue en fait d'environ 1 %, puisque les prix ont augmenté plus vite que le placement n'a gagné de valeur. Ceci illustre pourquoi « battre l'inflation » — pas seulement obtenir un rendement positif — importe pour véritablement faire croître la richesse dans le temps.

## Quiz Pratique
1. Qu'est-ce que l'inflation?
2. Qu'arrive-t-il au pouvoir d'achat si l'inflation dépasse les rendements de placement?
3. Vrai/Faux : Un solde de compte qui croît nominalement signifie toujours un pouvoir d'achat réel croissant.
4. Si un placement rapporte 5 % et que l'inflation est de 3 %, quel est le rendement réel approximatif?

## Corrigé
1. La hausse générale des prix dans le temps   2. Le pouvoir d'achat diminue malgré la croissance nominale du compte   3. Faux   4. Environ 2 %

## Réponses et Explications
1. Ceci est la définition fondamentale de l'inflation.
2. Ceci illustre la distinction réel contre nominal centrale à cette leçon.
3. La croissance nominale peut masquer la diminution du pouvoir d'achat réel si l'inflation la dépasse.
4. 5 % − 3 % = environ 2 % de rendement réel (une approximation simplifiée).

## Points Clés à Retenir
- L'inflation est la hausse générale des prix, érodant le pouvoir d'achat dans le temps.
- Les rendements nominaux doivent dépasser l'inflation pour que le pouvoir d'achat réel croisse vraiment.
- « Battre l'inflation » est une référence clé du placement à long terme, pas seulement obtenir un rendement positif.
