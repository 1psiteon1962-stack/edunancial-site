# WHITE-L1-020: O Que É Um IRA?

## Objetivos de Aprendizagem
1. Definir um IRA (conta individual de aposentadoria).
2. Distinguir um IRA de um 401(k).
3. Reconhecer que este é um tipo de conta específico dos EUA.

## Conteúdo Principal
*REGRA ESPECÍFICA DA REGIÃO:* Um IRA é uma conta de aposentadoria com vantagens fiscais dos EUA; esta lição descreve especificamente o conceito americano.

*FATO VERIFICADO:* Diferente de um 401(k), que é patrocinado pelo empregador, um IRA é aberto de forma independente por um indivíduo através de uma corretora ou instituição financeira, oferecendo poupança para aposentadoria com vantagens fiscais semelhantes, mas com limites de contribuição e regras diferentes.

## Exemplo Prático
*EXEMPLO ILUSTRATIVO:* O empregador de Omar não oferece um 401(k), então ele abre um IRA diretamente através de uma corretora. Ele contribui de forma independente todo ano, escolhendo seus próprios investimentos dentro da conta — um caminho disponível para ele independentemente dos benefícios de aposentadoria, se houver algum, que seu empregador ofereça.

## Questionário Prático
1. O que é um IRA?
2. Como um IRA difere de um 401(k) em termos de quem o abre?
3. Verdadeiro/Falso: Um IRA exige patrocínio do empregador para ser aberto.
4. Qual é uma semelhança chave entre IRAs e 401(k)s?

## Gabarito
1. Uma conta de aposentadoria com vantagens fiscais aberta individualmente   2. Um indivíduo abre um IRA diretamente; um 401(k) é patrocinado pelo empregador   3. Falso   4. Ambos oferecem poupança para aposentadoria com vantagens fiscais

## Respostas e Explicações
1. Esta é a definição fundamental de um IRA.
2. Esta é a distinção estrutural chave em relação a um 401(k).
3. IRAs podem ser abertos de forma independente, sem precisar de um plano do empregador.
4. Ambos os tipos de conta compartilham o objetivo geral de poupança para aposentadoria com vantagens fiscais.

## Principais Pontos a Lembrar
- Um IRA é uma conta de aposentadoria com vantagens fiscais dos EUA, aberta individualmente.
- Diferente de um 401(k), não exige patrocínio do empregador.
- Os limites de contribuição e regras específicas diferem entre IRAs e 401(k)s.
