## Learning Objectives

By the end of this lesson you will be able to:

- Define key performance indicators and explain their purpose
- Distinguish between leading indicators and lagging indicators
- Identify the core financial and operational KPIs every business should track
- Build a basic KPI dashboard for a business
- Use KPIs to identify performance gaps and trigger corrective action

## Core Content

### What Is a KPI?

A key performance indicator is a quantifiable measure that tracks a business's progress toward a specific goal. KPIs convert business activity into data that can be compared, trended, and acted upon.

Without KPIs, a business operates on intuition and anecdote. With KPIs, a business operates on evidence.

The word "key" is critical. Not every metric is a KPI. A KPI is a measurement that:
- Directly connects to business health or a specific objective
- Changes based on business performance (not external noise)
- Can be acted upon when it moves in the wrong direction

### Leading vs. Lagging Indicators

**Lagging indicators** measure what has already happened:
- Revenue last month
- Customer count at year-end
- Annual profit

Lagging indicators confirm results. They tell you what happened but do not help you change what is about to happen.

**Leading indicators** measure activity that predicts future results:
- Number of sales calls made this week
- New leads generated this month
- Proposals submitted this quarter

Leading indicators tell you whether the inputs are in place to produce the desired outputs. A business that only tracks lagging indicators is always looking backward. A business that tracks leading indicators can course-correct before results deteriorate.

Effective KPI dashboards include both — lagging to confirm results and leading to direct daily and weekly action.

### Core Financial KPIs

Every business should track these financial indicators regardless of industry:

**Revenue** — total money collected from customers in the period

**Gross Margin %** — (Revenue − COGS) ÷ Revenue. Tracks whether the core business is efficient.

**Operating Cash Flow** — actual cash generated from operations. Tracks survival, not just profitability.

**Customer Acquisition Cost (CAC)** — total marketing and sales cost ÷ new customers acquired. Measures the efficiency of growth spending.

**Customer Lifetime Value (LTV)** — average revenue per customer × average customer lifespan. Measures the long-term return on each customer relationship.

**LTV:CAC Ratio** — LTV ÷ CAC. A ratio above 3:1 generally indicates a sustainable growth model.

**Burn Rate (for early-stage businesses)** — monthly cash consumption above revenue. Measures how long the business can operate before requiring additional capital.

### Core Operational KPIs

Financial KPIs measure outcomes. Operational KPIs measure the activities that produce those outcomes.

**Sales conversion rate** — percentage of leads that become paying customers

**Average transaction value** — average revenue per sale or per customer visit

**Customer retention rate** — percentage of customers who return for repeat purchases

**Employee productivity** — revenue generated per employee or per labor hour

**Delivery time / cycle time** — how long it takes to fulfill an order or complete a service from customer commitment to delivery

Each of these has a direct connection to financial outcomes. Lower conversion rates drive up CAC. Lower retention drives down LTV. Slow delivery creates customer dissatisfaction and churn.

### Building a KPI Dashboard

A KPI dashboard should contain no more than 8–12 metrics. More than that and no one reads it — or acts on it.

A basic small-business KPI dashboard might include:

| KPI | This Week | Last Week | Target | Trend |
|-----|-----------|-----------|--------|-------|
| Revenue | | | | |
| Gross Margin % | | | | |
| New Leads | | | | |
| Sales Conversion % | | | | |
| New Customers | | | | |
| Cash Balance | | | | |
| Operating Cash Flow | | | | |
| CAC | | | | |

Update this weekly. Review for trends monthly. Act when any KPI deviates from target by more than a defined threshold.

### Acting on KPIs

A KPI that is tracked but not acted upon is a wasted effort. KPIs are only useful if the business has:

1. A defined target for each metric
2. A clear owner responsible for each metric
3. A process for reviewing the data on a regular cadence
4. A defined response when a metric falls below target

A business that tracks its conversion rate but does nothing when it drops from 25% to 15% has not used the KPI — it has merely recorded a failure.

Building the habit of weekly KPI review and monthly deep analysis is the discipline that separates businesses that grow from businesses that stagnate.

## Application

Before proceeding to the next lesson, complete the following:

1. List three metrics you currently track for your business (or a business you are analyzing). If you track none, identify three you could start tracking this week.
2. Classify each as a leading or lagging indicator.
3. For each metric, write the target you would need to hit for the business to be financially healthy.

If you cannot write a target, you do not yet understand the business well enough. That is valuable information — it tells you what to learn next.
