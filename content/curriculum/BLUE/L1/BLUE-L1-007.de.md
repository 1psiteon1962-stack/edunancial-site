# Was ist eine Kapitalgesellschaft?

## Lernziele
Am Ende dieser Lektion sollten Sie:
- eine Kapitalgesellschaft einfach definieren,
- erklären können, was es bedeutet, dass sie eine eigene juristische „Person“ ist,
- eine praktische Folge dieser rechtlichen Selbstständigkeit erklären können.

## Kerninhalt
### Eine eigene juristische Person
Eine Kapitalgesellschaft ist eine Unternehmensstruktur, die eine von ihren Eigentümern (Aktionären) vollständig getrennte Rechtseinheit schafft — in vieler Hinsicht formeller getrennt als eine LLC. Das Recht behandelt sie nahezu wie eine eigene „Person“: Sie kann Eigentum besitzen, Verträge schließen sowie klagen und verklagt werden, unabhängig von ihren Eigentümern.

### Warum die eigene Rechtspersönlichkeit wichtig ist
Wenn der Eigentümer einer Kapitalgesellschaft stirbt, endet das Unternehmen automatisch? Im Allgemeinen nicht. Da die Gesellschaft als eigene Rechtseinheit besteht, kann sie unabhängig vom Leben eines einzelnen Eigentümers fortbestehen.

### Eigentum durch Aktien
Kapitalgesellschaften gehören ihren Eigentümern über Aktien, die bereits im WHITE-Lernpfad eingeführt wurden. Das ist die direkte Verbindung zwischen „Aktien besitzen“ und dieser Unternehmensstruktur. Eine Gesellschaft kann einen oder Millionen Aktionäre haben; Aktien können gekauft und verkauft werden, ohne dass dadurch zwangsläufig der Geschäftsbetrieb gestört wird.

## Praxisbeispiel
Stellen Sie sich eine familiengeführte Kapitalgesellschaft vor, deren Gründer stirbt. Hört das Unternehmen rechtlich auf zu existieren? Nein: Das Eigentum an den Aktien wird durch Erbschaft, Verkauf oder auf andere Weise übertragen; die Gesellschaft selbst besteht unabhängig vom Leben einer einzelnen Person weiter.

## Übungsquiz
1. Eine Kapitalgesellschaft ist am besten beschrieben als:
   A. Dieselbe Rechtseinheit wie ihre Eigentümer
   B. Eine von ihren Eigentümern getrennte Rechtseinheit
   C. Nur für große Unternehmen verfügbar
   D. Eine Form des Einzelunternehmens
2. Richtig oder falsch: Eine Kapitalgesellschaft endet grundsätzlich, wenn ein einzelner Eigentümer stirbt.
3. Wie ist das Eigentum typischerweise strukturiert?
   A. Durch einen einzigen nicht übertragbaren Titel
   B. Durch Aktien, die einem oder vielen Aktionären gehören können
   C. Kapitalgesellschaften können niemandem gehören
   D. Der Staat bestimmt das Eigentum jährlich

## Lösungsschlüssel
1. B
2. Falsch
3. B

## Antworten und Erklärungen
### Frage 1
Richtige Antwort: B. Eine Kapitalgesellschaft ist rechtlich von ihren Eigentümern getrennt.
### Frage 2
Richtige Antwort: Falsch. Sie besteht grundsätzlich unabhängig vom Leben eines einzelnen Eigentümers fort.
### Frage 3
Richtige Antwort: B. Eigentum wird durch Aktien strukturiert.

## Wichtigste Erkenntnisse
- Eine Kapitalgesellschaft ist eine eigene, von ihren Eigentümern getrennte Rechtseinheit.
- Sie kann unabhängig von einem einzelnen Eigentümer fortbestehen.
- Eigentum wird über Aktien strukturiert und verbindet dieses Thema mit dem WHITE-Lernpfad.
