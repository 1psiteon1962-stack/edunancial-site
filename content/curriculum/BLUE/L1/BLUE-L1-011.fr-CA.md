# BLUE-L1-011 : Coûts de Démarrage — À Quoi S'Attendre

## Objectifs d'Apprentissage
1. Définir les coûts de démarrage.
2. Identifier les catégories courantes de coûts de démarrage.
3. Expliquer pourquoi sous-estimer les coûts de démarrage est une erreur précoce courante.

## Contenu Principal
Les coûts de démarrage sont les dépenses exceptionnelles engagées pour lancer une entreprise avant son ouverture. *FAIT VÉRIFIÉ :* Les catégories courantes incluent l'équipement, le stock initial, les frais juridiques et d'enregistrement, le marketing initial, les dépôts (pour les locaux ou les services publics), et une réserve de liquidités pour les premiers mois avant que les revenus ne se stabilisent.

*HYPOTHÈSE :* Sous-estimer les coûts de démarrage est une erreur précoce courante, souvent parce que les nouveaux propriétaires se concentrent sur les coûts évidents comme l'équipement tout en négligeant des coûts récurrents plus petits qui s'accumulent avant que des revenus significatifs n'arrivent.

## Exemple Pratique
*EXEMPLE ILLUSTRATIF :* En budgétisant l'ouverture d'un petit salon, Aisha tient compte de l'équipement et du stock initial, mais oublie initialement de budgétiser les mois précédant la constitution de sa clientèle — le loyer, les salaires, et les services publics qui doivent être payés peu importe le nombre de clients qui se présentent durant les premiers mois. Ajouter une réserve de liquidités pour cette période de démarrage s'avère aussi importante que l'équipement lui-même.

## Quiz Pratique
1. Que sont les coûts de démarrage?
2. Nomme deux catégories courantes de coûts de démarrage.
3. Vrai/Faux : Les coûts de démarrage n'incluent que des achats ponctuels comme l'équipement.
4. Pourquoi sous-estimer les coûts de démarrage est-il une erreur courante?

## Corrigé
1. Les dépenses exceptionnelles pour lancer une entreprise avant son démarrage   2. L'équipement, le stock initial (entre autres)   3. Faux   4. Les nouveaux propriétaires négligent souvent les coûts récurrents plus petits durant la période de démarrage

## Réponses et Explications
1. Ceci est la définition centrale des coûts de démarrage.
2. Celles-ci figurent parmi les catégories standard de coûts de démarrage.
3. Les coûts de démarrage incluent aussi une réserve de liquidités pour les dépenses d'exploitation précoces avant que les revenus ne se stabilisent.
4. Les coûts évidents sont budgétisés; le coût cumulé de survivre aux premiers mois est souvent négligé.

## Points Clés à Retenir
- Les coûts de démarrage sont les dépenses exceptionnelles nécessaires avant qu'une entreprise puisse être lancée.
- Les catégories courantes incluent l'équipement, le stock, les frais juridiques, et une réserve de liquidités précoce.
- Une réserve de liquidités pour la période de démarrage est aussi importante que les achats initiaux évidents.
