# Was ist eine EIN (Employer Identification Number)?

## Lernziele
- Eine EIN und ihren grundlegenden Zweck definieren.
- erklären, warum Unternehmen ohne Beschäftigte dennoch eine benötigen können.
- verstehen, wie eine EIN die geschäftliche Identität von der persönlichen Identität des Eigentümers trennt.

## Kerninhalt
### Thema 1: Was eine EIN ist
[REGIONSSPEZIFISCHE REGEL] Eine Employer Identification Number (EIN) ist eine eindeutige Nummer, die von der US-Bundesregierung zur steuerlichen Identifikation eines Unternehmens vergeben wird — ähnlich der Social Security Number für eine Person.

### Thema 2: Der irreführende Name
Trotz des Wortes „Employer“ beantragen viele Unternehmen ohne Beschäftigte eine EIN, etwa zur Eröffnung eines Geschäftskontos, für bestimmte Steuerformulare oder um die geschäftliche Identifikation von der persönlichen Social Security Number zu trennen.

### Thema 3: Warum die Trennung wichtig ist
[ILLUSTRATIVES BEISPIEL] Ein Einzelunternehmer, der für Bank- und Lieferantenunterlagen eine EIN statt seiner persönlichen Social Security Number nutzt, reduziert die Verbreitung seiner persönlichen Identifikationsnummer.

### Thema 4: Wer typischerweise eine benötigt
[REGIONSSPEZIFISCHE REGEL] Unternehmen mit Beschäftigten benötigen grundsätzlich eine EIN. Viele LLCs, Kapitalgesellschaften und Personengesellschaften benötigen sie unabhängig von der Mitarbeiterzahl. Manche Einzelunternehmer ohne Beschäftigte können stattdessen ihre Social Security Number verwenden.

## Wichtigste Erkenntnisse
- Eine EIN identifiziert in den USA ein Unternehmen für Steuerzwecke.
- Auch Unternehmen ohne Beschäftigte beantragen häufig eine.
- Sie unterstützt die Trennung von geschäftlicher und persönlicher Identität.
- Anforderungen hängen von Unternehmensform und Beschäftigungsstatus ab.
