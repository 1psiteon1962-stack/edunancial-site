# Was ist eine Bilanz, einfach erklärt?

## Lernziele
- eine Bilanz in einfachen Worten definieren.
- Vermögenswerte, Verbindlichkeiten und Eigenkapital unterscheiden.
- verstehen, dass eine Bilanz einen bestimmten Zeitpunkt abbildet.

## Kerninhalt
Eine Bilanz zeigt die finanzielle Position eines Unternehmens zu einem bestimmten Zeitpunkt.

Die Grundgleichung lautet:

**Vermögenswerte = Verbindlichkeiten + Eigenkapital**

Vermögenswerte sind Dinge von wirtschaftlichem Wert, die das Unternehmen besitzt oder kontrolliert. Verbindlichkeiten sind Verpflichtungen gegenüber anderen. Eigenkapital ist vereinfacht der verbleibende Anteil der Eigentümer nach Abzug der Verbindlichkeiten von den Vermögenswerten.

Im Gegensatz zur GuV, die einen Zeitraum betrachtet, ist die Bilanz eine Momentaufnahme.

## Wichtigste Erkenntnisse
- Die Bilanz zeigt die finanzielle Position zu einem bestimmten Zeitpunkt.
- Vermögenswerte = Verbindlichkeiten + Eigenkapital.
- Sie ergänzt die GuV, beantwortet aber eine andere finanzielle Frage.
