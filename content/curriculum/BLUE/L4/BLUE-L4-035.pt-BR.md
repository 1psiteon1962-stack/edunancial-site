# BLUE-L4-035: Análise dos efeitos de rede: por que alguns negócios ficam mais valiosos à medida que ganham mais clientes

## Cenário de abertura
SUPOSIÇÃO/OPINIÃO (cenário hipotético apenas para fins didáticos): Imagine duas grandes potências econômicas endurecendo, uma contra a outra, os controles de exportação de uma categoria de componentes de tecnologia avançada usados em muitos setores. À medida que as duas potências restringem o acesso dos usuários uma da outra a certas plataformas de tecnologia, os negócios que dependem muito do tamanho e das conexões da sua rede de usuários enfrentam um tipo de interrupção bem diferente dos negócios cujo valor vem só da qualidade do próprio produto. Esta lição examina a dinâmica específica que deixa os negócios que dependem de rede especialmente vulneráveis a esse tipo de fragmentação, e explica também por que os efeitos de rede são tão valiosos quando a rede está inteira.

## Objetivos de aprendizagem
- Explicar o que significam efeitos de rede no contexto de um negócio.
- Diferenciar efeitos de rede diretos de efeitos de rede indiretos.
- Explicar por que os efeitos de rede criam uma vantagem competitiva que se reforça sozinha e que pode ser difícil de superar para os concorrentes que chegam depois.
- Explicar por que fragmentar ou restringir a base de usuários de um negócio com efeitos de rede pode prejudicar o valor de fundo dele de forma desproporcional.

## Conteúdo principal
Os efeitos de rede descrevem uma situação em que um produto ou serviço fica mais valioso para cada usuário à medida que mais pessoas, no total, passam a usá-lo. FATO VERIFICADO: os efeitos de rede diretos acontecem quando o aumento de valor vem diretamente de mais usuários do mesmo tipo interagindo entre si (como em uma plataforma de comunicação ou rede social, em que cada usuário a mais aumenta diretamente o número de pessoas com quem cada usuário pode se conectar), enquanto os efeitos de rede indiretos acontecem quando o crescimento de um grupo de usuários aumenta o valor para outro grupo de usuários da mesma plataforma (como em um marketplace on-line, em que mais compradores atraem mais vendedores, e mais vendedores, por sua vez, atraem mais compradores).

Este é o porquê de os efeitos de rede criarem uma vantagem competitiva que se reforça sozinha e que pode ser realmente difícil de superar para os concorrentes que chegam depois, ligado à análise da vantagem do pioneiro da Lição 33: um negócio com efeitos de rede que já tem uma base de usuários importante oferece a cada novo usuário em potencial bem mais valor (mais pessoas com quem se conectar ou negociar) do que uma plataforma concorrente mais nova e menor consegue oferecer hoje. Por isso é difícil para o novo concorrente tirar usuários da rede maior, que já é valiosa, mesmo que a tecnologia de fundo do produto dele seja, no resto, parecida ou até melhor. É exatamente o tipo de mecanismo de vantagem competitiva duradoura que a Lição 33 apontou como favorável a uma estratégia de pioneiro ou de líder desde cedo.

É por isso que fragmentar ou restringir a base de usuários de um negócio com efeitos de rede, como poderia acontecer com as restrições de acesso a plataformas descritas no cenário, pode prejudicar de forma desproporcional o valor de fundo desse negócio, além do que uma simples perda proporcional de usuários faria pensar. Como o valor central da plataforma depende justamente do tamanho e das conexões da rede como um todo, dividir artificialmente essa rede em partes separadas que não interagem entre si (por exemplo, usuários de um país que não conseguem mais interagir com usuários de outro) reduz o valor percebido por cada usuário que ficou, não só para os usuários excluídos, mas também para os que continuam ligados a uma rede agora menor e menos valiosa. É um efeito que se acumula, diferente da perda de receita mais simples e proporcional que um negócio sem efeitos de rede relevantes teria ao perder a mesma porcentagem da sua base total de usuários.

## Exemplo prático
EXEMPLO ILUSTRATIVO: Uma plataforma de comunicação com fortes efeitos de rede diretos construiu uma base de usuários global grande e muito conectada, o que a torna bem mais valiosa para cada usuário do que uma plataforma concorrente mais nova e menor, com muito menos usuários com quem se conectar. Quando o endurecimento das restrições tecnológicas entre duas grandes potências econômicas obriga a plataforma a dividir a sua base de usuários em duas redes regionais que não interagem entre si, o valor percebido por cada usuário que ficou cai bastante, já que os usuários de cada rede recém-separada não conseguem mais se conectar com os usuários que agora ficaram na outra rede. É uma perda de valor para os dois grupos de usuários que ficaram que vai muito além do que uma simples conta proporcional dos usuários afetados faria pensar, justamente porque o valor central da plataforma dependia do tamanho e das conexões da sua rede como um todo, antes unida.

## Teste de prática
**P1. O que o termo efeitos de rede descreve?**
A) Uma situação em que um produto fica menos valioso à medida que mais pessoas o usam
B) Uma situação em que um produto ou serviço fica mais valioso para cada usuário à medida que mais pessoas, no total, passam a usá-lo
C) Uma estratégia de preço usada só por empresas de telecomunicações
D) Um tipo de instrumento financeiro usado para se proteger do risco cambial

**P2. Qual é a diferença entre efeitos de rede diretos e indiretos?**
A) Os efeitos de rede diretos só valem para produtos físicos, e os indiretos só para serviços digitais
B) Os efeitos de rede diretos acontecem quando o valor aumenta porque mais usuários do mesmo tipo interagem diretamente, enquanto os indiretos acontecem quando o crescimento de um grupo de usuários aumenta o valor para outro grupo da mesma plataforma
C) Não há diferença relevante entre efeitos de rede diretos e indiretos
D) Os efeitos de rede indiretos sempre envolvem mais usuários do que os diretos

**P3. Por que os efeitos de rede podem criar uma vantagem competitiva difícil de superar para os concorrentes que chegam depois?**
A) Os efeitos de rede não têm relação com a posição competitiva de um negócio em relação a quem chega depois
B) Uma rede que já é grande oferece a cada novo usuário bem mais valor do que uma plataforma concorrente mais nova e menor consegue oferecer hoje, o que torna difícil para a plataforma mais nova tirar usuários, mesmo com uma tecnologia de fundo parecida ou melhor
C) Os concorrentes que chegam depois sempre têm uma vantagem natural sobre qualquer negócio com efeitos de rede que já existe
D) Os efeitos de rede só beneficiam a primeira empresa a entrar em um mercado, sem nenhuma importância competitiva ao longo do tempo

**P4. Por que fragmentar a base de usuários de um negócio com efeitos de rede pode prejudicar o seu valor de forma desproporcional, além de uma simples perda proporcional de usuários?**
A) Fragmentar a base de usuários não tem nenhum efeito sobre o valor de um negócio com efeitos de rede além da perda proporcional dos usuários excluídos
B) Como o valor central da plataforma depende do tamanho e das conexões da rede como um todo, dividi-la em partes separadas que não interagem reduz o valor também para os usuários que ficaram, e não só para os excluídos
C) Fragmentar a base de usuários de um negócio com efeitos de rede sempre aumenta o valor total da plataforma
D) Os efeitos de rede desaparecem totalmente assim que um único usuário sai da plataforma

**P5. No exemplo, por que dividir a base de usuários da plataforma de comunicação em duas redes regionais que não interagem prejudicou o valor para os usuários das duas redes que ficaram?**
A) Na verdade, a separação aumentou o valor percebido pelos usuários das duas redes que ficaram
B) Cada rede regional que ficou passou a ser menor e menos conectada do que a rede unida original, o que reduziu o valor percebido por cada usuário que ficou, agora ligado a uma rede com menos pessoas para alcançar
C) A separação não teve nenhum efeito sobre o valor da plataforma para nenhum usuário
D) Só os usuários totalmente excluídos da plataforma tiveram alguma perda de valor

## Respostas e explicações
**P1.** Os efeitos de rede descrevem justamente essa relação positiva entre o tamanho da base total de usuários e o valor percebido por cada usuário.

**P2.** Essa diferença mostra se a interação que aumenta o valor acontece dentro do mesmo tipo de grupo de usuários (diretos) ou entre grupos de usuários diferentes e complementares da mesma plataforma (indiretos).

**P3.** A vantagem de valor que se reforça sozinha de uma rede que já é grande cria uma barreira estrutural real que a qualidade do produto, sozinha, muitas vezes não consegue superar para um concorrente menor que chegou depois.

**P4.** A perda de valor que se acumula para os usuários que ficam em cada parte da rede, agora menor e separada, é o mecanismo específico que torna a fragmentação desproporcionalmente prejudicial justamente para os negócios com efeitos de rede.

**P5.** Isso mostra diretamente o prejuízo que se acumula, típico dos efeitos de rede, descrito nesta lição: a perda de valor vai além dos usuários afetados diretamente e atinge todos que continuam ligados a uma rede agora menor e fragmentada.

## Pontos-chave
- Os efeitos de rede descrevem um produto ou serviço que fica mais valioso para cada usuário à medida que a base total de usuários cresce, por mecanismos diretos ou indiretos.
- Uma rede que já é grande cria uma vantagem competitiva que se reforça sozinha e é difícil de superar para concorrentes menores que chegam depois.
- Os negócios com efeitos de rede dependem justamente do tamanho e das conexões da sua base total de usuários para o seu valor central.
- Fragmentar a base de usuários de um negócio com efeitos de rede pode prejudicar de forma desproporcional o valor para os usuários que ficam, além do que uma simples perda proporcional de usuários faria pensar.
