# GOLD-L3-037: Warum eine Anlagethese widerlegbar sein sollte

## Lernziele
Am Ende dieser Lektion kannst du:
- erklären, was es bedeutet, dass eine Anlagethese widerlegbar ist
- erklären, warum eine nicht widerlegbare These ein Warnzeichen und kein Zeichen starker Überzeugung ist
- dieses Konzept mit der antizyklischen Überzeugung aus Lektion 35 verbinden

## Hauptinhalt

Lektion 35 hat gezeigt, dass echte antizyklische Überzeugung eine konkrete, klar formulierte Grundlage braucht und nicht bloß Widerspruch zur Masse. Hier ein verwandter, allgemeinerer Grundsatz: Eine solide Anlagethese sollte **widerlegbar** sein – sie sollte im Voraus angeben, welche Art von Belegen oder Ergebnissen darauf hindeuten würde, dass die These falsch war.

Hier das „Warum“, weshalb das wichtig ist: Eine These, die jedes Ergebnis als Bestätigung aufnehmen kann – steigende Kurse bestätigen sie, fallende Kurse werden als „vorübergehendes Rauschen“ oder „der Markt erkennt den wahren Wert noch nicht“ abgetan –, liefert überhaupt keine nützliche, überprüfbare Information. [VERIFIED FACT] Diese Art nicht widerlegbaren Denkens ist ein belegtes Muster der Verhaltensökonomie, das manchmal mit dem Bestätigungsfehler in Verbindung gebracht wird: Belege werden so gedeutet, dass sie eine bereits bestehende Überzeugung stützen, statt sie wirklich als mögliche Bestätigung oder Widerlegung abzuwägen.

Deshalb versuchen disziplinierte Anleger grundsätzlich, vor einer bedeutenden Anlage konkrete Bedingungen oder Belege zu benennen, die ihre Meinung ändern würden – nicht weil sie erwarten, falschzuliegen, sondern weil diese Disziplin im Voraus eine ehrlichere, vollständigere Prüfung der These erzwingt und eine echte Grundlage schafft, die Position später neu zu bewerten, falls genau diese Belege tatsächlich eintreten.

## Durchgerechnetes Beispiel

[ILLUSTRATIVE EXAMPLE] Eine Anlegerin entwickelt eine These für eine bestimmte alternative Anlage und benennt vor der Kapitalbindung ausdrücklich mehrere konkrete Bedingungen, die, falls sie eintreten, darauf hindeuten würden, dass ihre These falsch war, und sie dazu bringen sollen, die Position zu überdenken. [ASSUMPTION] Als Monate später eine dieser Bedingungen tatsächlich eintritt, hat sie eine klare, vorab festgelegte Grundlage, ihre Position ehrlich neu zu bewerten, statt die ungünstige Entwicklung reflexhaft als unwichtiges Rauschen abzutun – eine Disziplin, die ihr eine weniger widerlegbare, beliebig dehnbare These nicht gegeben hätte.

## Übungsquiz
1. Was bedeutet es, dass eine Anlagethese widerlegbar ist?
2. Warum gilt eine nicht widerlegbare These als Warnzeichen und nicht als Zeichen starker Überzeugung?
3. Warum hat es echten praktischen Wert, im Voraus konkrete widerlegende Bedingungen zu benennen?

## Lösungsschlüssel
1. Sie gibt im Voraus an, welche Art von Belegen oder Ergebnissen darauf hindeuten würde, dass die These falsch war, statt jedes Ergebnis als Bestätigung aufnehmen zu können.
2. Weil eine These, die jedes Ergebnis als Bestätigung deutet, keine nützliche, überprüfbare Information liefert – dieses Muster hängt mit dem Bestätigungsfehler zusammen, bei dem Belege so gedeutet werden, dass sie eine bestehende Überzeugung stützen, statt sie wirklich abzuwägen.
3. Es erzwingt im Voraus eine ehrlichere, vollständigere Prüfung und schafft eine klare, vorab festgelegte Grundlage, die Position später neu zu bewerten, falls genau diese widerlegenden Belege tatsächlich eintreten.

## Antworten und Erklärungen
1. Das ist die grundlegende Definition dieser Lektion.
2. Das ist die zentrale Warnung, anknüpfend an eine belegte Verhaltensverzerrung.
3. Das unterstreicht den praktischen, vorausschauenden Wert dieser Disziplin.

## Das Wichtigste in Kürze
- Eine solide Anlagethese sollte widerlegbar sein und im Voraus angeben, welche Belege darauf hindeuten würden, dass sie falsch war.
- Eine nicht widerlegbare These, die jedes Ergebnis als Bestätigung aufnimmt, ist ein Warnzeichen und hängt oft mit dem Bestätigungsfehler zusammen.
- Im Voraus konkrete widerlegende Bedingungen zu benennen schafft eine echte, ehrliche Grundlage, eine Position später neu zu bewerten.
