# GREEN-L1-034 : L'Impôt sur le Revenu — Les Bases

## Objectifs d'Apprentissage
1. Définir l'impôt sur le revenu en termes simples.
2. Expliquer le concept général d'un système d'imposition progressif.
3. Reconnaître que les taux spécifiques varient selon le pays.

## Contenu Principal
*RÈGLE SPÉCIFIQUE À LA RÉGION :* Les taux spécifiques de l'impôt sur le revenu et les structures exactes varient considérablement selon le pays ; cette leçon décrit uniquement le concept général.

L'impôt sur le revenu est un impôt généralement appliqué sur le revenu qu'une personne ou une entreprise perçoit pendant une période donnée. *SUPPOSITION :* De nombreux pays utilisent un système progressif, où le taux d'imposition augmente généralement à mesure que le niveau de revenu augmente — cela signifie que les personnes ayant des revenus plus élevés paient généralement un pourcentage plus élevé sur ces revenus que les personnes ayant des revenus plus faibles.

## Exemple Pratique
*EXEMPLE ILLUSTRATIF :* Dans un système progressif simplifié, quelqu'un pourrait payer un taux de 10 % sur les premiers 20 000 $ de revenu, et un taux de 20 % sur tout revenu supplémentaire au-delà de ce montant. Cela signifie généralement qu'une personne ne paie pas le taux le plus élevé sur l'ensemble de son revenu, mais uniquement sur la partie dépassant chaque tranche établie.

## Quiz Pratique
1. Qu'est-ce que l'impôt sur le revenu ?
2. Qu'est-ce qu'un système d'imposition progressif ?
3. Vrai/Faux : Dans un système progressif, toutes les personnes paient exactement le même pourcentage.
4. Dans l'exemple, quel taux s'appliquerait aux premiers 20 000 $ de revenu ?

## Corrigé
1. Un impôt appliqué sur le revenu perçu pendant une période donnée   2. Un système où le taux d'imposition augmente à mesure que le revenu augmente   3. Faux   4. 10 %

## Réponses et Explications
1. Ceci est la définition fondamentale de l'impôt sur le revenu.
2. Ceci est la définition fondamentale d'un système d'imposition progressif.
3. Dans un système progressif, le taux varie généralement selon le niveau de revenu.
4. Selon l'exemple, le taux de 10 % s'appliquerait aux premiers 20 000 $.

## Points Clés à Retenir
- L'impôt sur le revenu s'applique généralement sur le revenu perçu.
- De nombreux pays utilisent un système progressif, où le taux augmente avec le niveau de revenu.
- Les taux spécifiques et les structures varient considérablement selon le pays.
