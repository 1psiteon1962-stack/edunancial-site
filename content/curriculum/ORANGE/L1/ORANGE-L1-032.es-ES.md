# El concepto de CRM (incluso una hoja de cálculo sirve)

## Objetivos de aprendizaje
- Definir CRM independientemente de un software específico.
- Explicar por qué registrar sistemáticamente a los posibles clientes evita perder ventas.
- Crear un sistema básico de seguimiento.

## Contenido principal

CRM significa gestión de relaciones con clientes. Aunque suele asociarse con software caro, el concepto es sencillo: un sistema para registrar quiénes son tus posibles clientes y clientes, en qué etapa están y qué debe ocurrir después con cada uno. Una hoja de cálculo bien organizada es un CRM perfectamente válido para una operación pequeña; el software es una comodidad, no un requisito.

Sin sistema, el vendedor depende de la memoria, que falla a medida que aumenta el número de contactos. Se olvidan seguimientos, clientes potenciales importantes se enfrían y resulta imposible detectar patrones porque nada queda registrado.

Como mínimo, un CRM básico debe registrar nombre y datos de contacto, etapa del embudo, fecha del último contacto y siguiente acción necesaria. Eso evita muchas de las formas habituales en que una oportunidad se pierde.

## Ejemplo práctico

Alguien que contactó con más de cien compañías discográficas mantuvo una lista escrita con nombre de empresa, contacto, respuesta y notas de seguimiento. Era un CRM aunque no utilizara software. Permitía saber a quién volver a llamar, quién había aceptado y quién necesitaba seguimiento.

## Cuestionario práctico
1. ¿Qué significa CRM y cuál es su propósito?
2. ¿Debe ser software caro?
3. ¿Qué ocurre cuando no existe sistema?
4. Nombra los cuatro campos mínimos.

## Respuestas
1. Gestión de relaciones con clientes; sirve para registrar contactos, etapas y siguientes pasos.
2. No. Una hoja de cálculo o lista organizada puede servir.
3. Se olvidan seguimientos y se pierden oportunidades.
4. Nombre/contacto, etapa, último contacto y siguiente acción.

## Respuestas y explicaciones
1. CRM es un concepto antes que una herramienta.
2. El software facilita el trabajo, pero no define el sistema.
3. La memoria deja de ser fiable cuando crece el volumen.
4. Estos campos forman una estructura mínima viable.

## Puntos clave
- CRM significa organizar relaciones y próximos pasos, no comprar software caro.
- Sin un sistema, las oportunidades se pierden.
- Una hoja de cálculo sencilla puede cubrir lo esencial.
