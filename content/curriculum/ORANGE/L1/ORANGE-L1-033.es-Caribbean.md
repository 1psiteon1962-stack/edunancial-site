# Seguimiento de una cartera de ventas

## Objetivos de aprendizaje
- Definir una cartera de ventas y su propósito.
- Identificar etapas básicas.
- Clasificar posibles clientes por etapa.

## Contenido principal

Una cartera de ventas organiza a cada posible cliente activo según lo avanzado que esté en su proceso de decisión. Permite ver rápidamente dónde está el negocio y qué necesita atención. Es la aplicación práctica del embudo de ventas a personas concretas.

Las etapas habituales incluyen: Nuevo contacto, Contactado, Interesado, Propuesta enviada y Cerrado —ganado o perdido—. Cada persona ocupa una etapa y avanza, o a veces retrocede, conforme evoluciona la relación.

Este seguimiento responde preguntas esenciales: ¿cuántas oportunidades están cerca de cerrarse?, ¿dónde se atascan?, ¿entra suficiente volumen arriba para alcanzar objetivos futuros teniendo en cuenta cuántas oportunidades se pierden durante el proceso?

## Ejemplo práctico

Una consultora revisa semanalmente su cartera. Observa quince contactos en «Contactado» desde hace más de tres semanas sin movimiento: su seguimiento necesita atención. Solo dos están en «Propuesta enviada», insuficientes para su objetivo mensual aunque ambos cierren. Esa visibilidad le permite actuar antes de que aparezca el déficit.

## Cuestionario práctico
1. Define una cartera de ventas.
2. Nombra tres etapas habituales.
3. ¿Qué preguntas ayuda a responder?
4. ¿Qué problemas reveló el ejemplo?

## Respuestas
1. Un sistema para organizar posibles clientes según su etapa de decisión.
2. Por ejemplo: Nuevo contacto, Contactado, Interesado, Propuesta enviada y Cerrado.
3. Cuántos están cerca de cerrar, dónde se atascan y si entra suficiente volumen.
4. Seguimientos estancados y pocas propuestas para alcanzar el objetivo.

## Respuestas y explicaciones
1. La cartera aplica el embudo a oportunidades individuales.
2. Las etapas convierten el proceso en algo visible y gestionable.
3. La visibilidad permite tomar decisiones antes de sufrir las consecuencias.
4. El análisis reveló problemas corregibles antes de convertirse en una crisis de ingresos.

## Puntos clave
- Una cartera organiza oportunidades reales por etapa.
- Revisarla regularmente muestra dónde actuar.
- La visibilidad permite anticipar problemas de ingresos.
