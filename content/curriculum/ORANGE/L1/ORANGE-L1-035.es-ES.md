# Fundamentos de las pruebas A/B

## Objetivos de aprendizaje
- Definir una prueba A/B y su propósito.
- Identificar los requisitos de una prueba válida.
- Diseñar una prueba sencilla para una decisión de marketing.

## Contenido principal

Una prueba A/B compara dos versiones de algo —un anuncio, asunto de correo o página web— mostrándolas a audiencias similares y midiendo cuál funciona mejor. En vez de adivinar, permite que los resultados reales decidan.

Para ser válida debe cambiar una sola variable cada vez. Si cambias simultáneamente el asunto y el contenido de un correo, no sabrás cuál produjo la diferencia. También necesita una audiencia suficientemente grande; unas pocas personas pueden generar resultados engañosos por azar.

No es una herramienta exclusiva de grandes empresas. Un pequeño negocio puede comparar dos textos en publicaciones similares o dos asuntos en su lista de correo y utilizar lo aprendido para mejorar decisiones futuras.

## Ejemplo práctico

Un negocio prueba dos asuntos: A: «20 % de descuento solo esta semana» y B: «Tu descuento está preparado». Envía cada versión a la mitad de la lista, manteniendo idénticos el contenido y la hora. A obtiene un 30 % de aperturas y B un 18 %. Ahora existe evidencia real de que, para esa audiencia y prueba, la especificidad y urgencia funcionaron mejor.

## Cuestionario práctico
1. Define una prueba A/B.
2. ¿Qué necesita para producir resultados útiles?
3. ¿Por qué una muestra muy pequeña es poco fiable?
4. ¿Solo sirve para empresas grandes?

## Respuestas
1. Comparar dos versiones ante audiencias similares para medir cuál funciona mejor.
2. Cambiar una variable y disponer de suficiente información.
3. Porque el azar puede dominar los resultados.
4. No. Los pequeños negocios también pueden utilizarla.

## Respuestas y explicaciones
1. La comparación sustituye suposiciones por evidencia.
2. Aislar la variable permite atribuir correctamente el resultado.
3. Las muestras pequeñas pueden producir falsas conclusiones.
4. Las pruebas sencillas pueden aplicarse a decisiones pequeñas y frecuentes.

## Puntos clave
- Las pruebas A/B convierten decisiones de marketing en experimentos.
- Cambia una variable cada vez.
- Incluso los negocios pequeños pueden aprender mediante pruebas sencillas.
