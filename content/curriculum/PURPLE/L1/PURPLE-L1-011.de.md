# PURPLE-L1-011: Garantien — Ausdrücklich vs. Stillschweigend

## Lernziele
1. Garantie in allgemeinen Worten definieren.
2. Eine ausdrückliche von einer stillschweigenden Garantie unterscheiden.
3. Ein übliches Beispiel für eine stillschweigende Garantie erkennen.

## Kerninhalt
Eine Garantie ist ein Versprechen bezüglich der Qualität, Leistung, oder des Zustands eines Produkts oder einer Dienstleistung. *FAKT ÜBERPRÜFT:* Eine **ausdrückliche Garantie** ist ein Versprechen, das vom Verkäufer oder Hersteller ausdrücklich abgegeben wird, sei es schriftlich oder mündlich. Eine **stillschweigende Garantie** entsteht üblicherweise automatisch kraft Gesetzes, ohne dass jemand sie erklären muss, basierend auf vernünftigen Erwartungen an das Produkt.

*ANNAHME:* Ein häufig genanntes Beispiel für eine stillschweigende Garantie ist die "Garantie der Handelsüblichkeit", die üblicherweise nahelegt, dass ein von einem Händler verkauftes Produkt für seinen gewöhnlichen Zweck angemessen gut funktioniert — wobei die genauen Details und Ausnahmen je nach Rechtssystem variieren.

## Praktisches Beispiel
*VERANSCHAULICHENDES BEISPIEL:* Erklärt ein Haushaltsgerätehersteller schriftlich, dass eine Waschmaschine "zwei Jahre Garantie gegen Mängel" hat, ist dies eine ausdrückliche Garantie. Auch ohne diese schriftliche Erklärung würde das Recht üblicherweise stillschweigend erwarten, dass eine neue Waschmaschine tatsächlich angemessen Wäsche wäscht — diese grundlegende Erwartung deckt die stillschweigende Garantie der Handelsüblichkeit ab.

## Praktisches Quiz
1. Was ist eine ausdrückliche Garantie?
2. Was ist eine stillschweigende Garantie?
3. Wahr/Falsch: Eine stillschweigende Garantie muss schriftlich erklärt werden, um zu bestehen.
4. Nenne ein häufig genanntes Beispiel für eine stillschweigende Garantie.

## Lösungsschlüssel
1. Ein vom Verkäufer oder Hersteller ausdrücklich abgegebenes Versprechen   2. Ein Versprechen, das automatisch kraft Gesetzes aufgrund vernünftiger Erwartungen entsteht   3. Falsch   4. Die Garantie der Handelsüblichkeit

## Antworten und Erklärungen
1. Dies ist die grundlegende Definition einer ausdrücklichen Garantie.
2. Dies ist die grundlegende Definition einer stillschweigenden Garantie.
3. Stillschweigende Garantien entstehen automatisch kraft Gesetzes, ohne dass eine Erklärung erforderlich ist.
4. Dies ist ein häufig genanntes Beispiel, wobei die Details je nach Rechtssystem variieren.

## Wichtigste Punkte zum Merken
- Eine ausdrückliche Garantie ist ein vom Verkäufer oder Hersteller ausdrücklich abgegebenes Versprechen.
- Eine stillschweigende Garantie entsteht automatisch kraft Gesetzes aufgrund vernünftiger Erwartungen.
- Die Garantie der Handelsüblichkeit ist ein häufig genanntes Beispiel für eine stillschweigende Garantie.
