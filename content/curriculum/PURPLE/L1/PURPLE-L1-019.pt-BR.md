# PURPLE-L1-019: A Procuração Explicada

## Objetivos de Aprendizagem
1. Definir procuração em termos simples.
2. Distinguir uma procuração geral de uma procuração limitada.
3. Explicar quando uma procuração geralmente termina.

## Conteúdo Principal
*FATO VERIFICADO:* Uma procuração é um documento jurídico que autoriza uma pessoa (o "procurador") a agir em nome de outra pessoa (o "outorgante") em assuntos jurídicos ou financeiros específicos. Uma procuração **geral** geralmente concede amplos poderes sobre muitos assuntos, enquanto uma procuração **limitada** geralmente restringe o poder a uma tarefa ou período específico.

*SUPOSIÇÃO:* Uma procuração padrão geralmente termina se o outorgante ficar incapacitado ou falecer, a menos que o documento seja especificamente designado como uma procuração "duradoura", geralmente projetada para permanecer válida mesmo se o outorgante ficar incapacitado.

## Exemplo Prático
*EXEMPLO ILUSTRATIVO:* Uma pessoa que viajará para o exterior por vários meses poderia outorgar uma procuração limitada a um familiar, autorizando-o apenas a lidar com o pagamento de contas específicas enquanto estiver fora. Já uma pessoa preocupada com uma possível incapacidade futura devido à idade poderia outorgar uma procuração duradoura mais ampla, para que um ente querido de confiança possa administrar seus assuntos financeiros caso ela se torne incapaz de fazê-lo sozinha.

## Questionário Prático
1. O que é uma procuração?
2. Qual é a diferença geral entre uma procuração geral e uma procuração limitada?
3. Verdadeiro/Falso: Todas as procurações permanecem válidas automaticamente se o outorgante ficar incapacitado.
4. Que tipo de procuração é projetada para permanecer válida durante a incapacidade?

## Gabarito
1. Um documento jurídico que autoriza alguém a agir em nome de outra pessoa   2. A geral concede amplos poderes; a limitada restringe o poder a uma tarefa ou período específico   3. Falso   4. A procuração duradoura

## Respostas e Explicações
1. Esta é a definição fundamental de uma procuração.
2. Esta é a distinção geral entre esses dois tipos de procuração.
3. Uma procuração padrão geralmente termina com a incapacidade, a menos que seja designada como duradoura.
4. A procuração duradoura é especificamente projetada para esse propósito.

## Principais Pontos a Lembrar
- Uma procuração autoriza alguém a agir em nome de outra pessoa em assuntos jurídicos ou financeiros.
- Ela pode ser geral (amplos poderes) ou limitada (poder restrito a uma tarefa ou período).
- Uma procuração duradoura é projetada para permanecer válida mesmo durante a incapacidade do outorgante.
