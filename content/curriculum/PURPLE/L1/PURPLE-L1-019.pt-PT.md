# PURPLE-L1-019: A Procuração Explicada

## Objetivos de Aprendizagem
1. Definir procuração em termos simples.
2. Distinguir uma procuração geral de uma procuração limitada.
3. Explicar quando termina geralmente uma procuração.

## Conteúdo Principal
*FACTO VERIFICADO:* Uma procuração é um documento jurídico que autoriza uma pessoa (o "procurador") a agir em nome de outra pessoa (o "mandante") em assuntos jurídicos ou financeiros específicos. Uma procuração **geral** concede geralmente amplos poderes sobre muitos assuntos, enquanto uma procuração **limitada** restringe geralmente o poder a uma tarefa ou período específico.

*SUPOSIÇÃO:* Uma procuração normal termina geralmente se o mandante ficar incapacitado ou falecer, a menos que o documento seja especificamente designado como uma procuração "duradoura", geralmente concebida para permanecer válida mesmo que o mandante fique incapacitado.

## Exemplo Prático
*EXEMPLO ILUSTRATIVO:* Uma pessoa que viajará para o estrangeiro durante vários meses poderia conceder uma procuração limitada a um familiar, autorizando-o apenas a tratar do pagamento de contas específicas enquanto estiver fora. Já uma pessoa preocupada com uma possível incapacidade futura devido à idade poderia conceder uma procuração duradoura mais ampla, para que um ente querido de confiança possa gerir os seus assuntos financeiros caso ela se torne incapaz de o fazer sozinha.

## Questionário Prático
1. O que é uma procuração?
2. Qual é a diferença geral entre uma procuração geral e uma procuração limitada?
3. Verdadeiro/Falso: Todas as procurações permanecem válidas automaticamente em caso de incapacidade do mandante.
4. Que tipo de procuração é concebida para permanecer válida durante a incapacidade?

## Chave de Respostas
1. Um documento jurídico que autoriza alguém a agir em nome de outra pessoa   2. A geral concede amplos poderes; a limitada restringe o poder a uma tarefa ou período específico   3. Falso   4. A procuração duradoura

## Respostas e Explicações
1. Esta é a definição fundamental de uma procuração.
2. Esta é a distinção geral entre estes dois tipos de procuração.
3. Uma procuração normal termina geralmente com a incapacidade, a menos que seja designada como duradoura.
4. A procuração duradoura é especificamente concebida para este propósito.

## Pontos-Chave a Reter
- Uma procuração autoriza alguém a agir em nome de outra pessoa em assuntos jurídicos ou financeiros.
- Pode ser geral (amplos poderes) ou limitada (poder restrito a uma tarefa ou período).
- Uma procuração duradoura é concebida para permanecer válida mesmo durante a incapacidade do mandante.
