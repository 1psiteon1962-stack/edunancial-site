# PURPLE-L1-043: Vertraulichkeitsvereinbarungen (NDA)

## Lernziele
1. Eine Vertraulichkeitsvereinbarung in allgemeinen Worten definieren.
2. Eine einseitige von einer gegenseitigen NDA unterscheiden.
3. Eine übliche Situation erklären, in der eine NDA verwendet wird.

## Kerninhalt
*FAKT ÜBERPRÜFT:* Eine Vertraulichkeitsvereinbarung (häufig als "NDA" bezeichnet, vom englischen "non-disclosure agreement") ist ein Vertrag, in dem eine oder mehrere Parteien vereinbaren, bestimmte Informationen vertraulich zu behandeln und sie nicht ohne Genehmigung an Dritte weiterzugeben.

*ANNAHME:* Eine **einseitige** NDA bedeutet üblicherweise, dass nur eine Partei vertrauliche Informationen teilt, wobei die Vertraulichkeitspflicht ausschließlich der anderen Partei obliegt, während eine **gegenseitige** NDA üblicherweise bedeutet, dass beide Parteien vertrauliche Informationen miteinander teilen, wobei beide zur Geheimhaltung verpflichtet sind.

## Praktisches Beispiel
*VERANSCHAULICHENDES BEISPIEL:* Ein Unternehmen, das einen externen Berater beauftragt, seine vertraulichen Geschäftspläne zu prüfen, würde diesen üblicherweise bitten, eine einseitige NDA zu unterzeichnen, da nur das Unternehmen sensible Informationen teilt. Zwei Unternehmen hingegen, die eine mögliche Fusion prüfen und vertrauliche Finanzinformationen miteinander teilen müssen, würden üblicherweise eine gegenseitige NDA unterzeichnen, da beide Parteien sensible Informationen offenlegen.

## Praktisches Quiz
1. Was ist eine Vertraulichkeitsvereinbarung (NDA)?
2. Was ist eine einseitige NDA?
3. Wahr/Falsch: Bei einer gegenseitigen NDA hat nur eine Partei die Vertraulichkeitspflicht.
4. Im Fusionsbeispiel — warum würde eine gegenseitige NDA verwendet?

## Lösungsschlüssel
1. Ein Vertrag, in dem die Parteien vereinbaren, bestimmte Informationen vertraulich zu behandeln   2. Nur eine Partei teilt Informationen, und nur die andere Partei hat die Vertraulichkeitspflicht   3. Falsch   4. Weil beide Unternehmen sensible Informationen miteinander teilen

## Antworten und Erklärungen
1. Dies ist die grundlegende Definition einer Vertraulichkeitsvereinbarung.
2. Dies ist die grundlegende Definition einer einseitigen NDA.
3. Bei einer gegenseitigen NDA haben üblicherweise beide Parteien die Vertraulichkeitspflicht.
4. Dass beide Parteien sensible Informationen teilen, ist der allgemeine Grund für die Verwendung einer gegenseitigen NDA.

## Wichtigste Punkte zum Merken
- Eine NDA ist ein Vertrag, in dem die Parteien vereinbaren, bestimmte Informationen vertraulich zu behandeln.
- Eine einseitige NDA bedeutet, dass nur eine Partei Informationen teilt; eine gegenseitige NDA bedeutet, dass beide es tun.
- Die Wahl zwischen beiden hängt üblicherweise davon ab, wer sensible Informationen in der Beziehung teilt.
