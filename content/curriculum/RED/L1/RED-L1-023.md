# What Is a Cap Rate? (Introductory Version)

## Learning Objectives

By the end of this lesson, you should be able to:

- State the basic cap rate formula.
- Explain what a cap rate estimates.
- Recognize that cap rate is a starting comparison tool, not a complete
  valuation method.

## Core Content

### The Basic Formula

Cap Rate = Net Operating Income ÷ Property Value.

Net operating income (NOI) is a property's income after operating
expenses, but before mortgage payments — a more detailed introduction to
NOI comes in Level 2.

### What It Estimates

A cap rate gives a rough estimate of a property's potential return as an
all-cash investment, expressed as a percentage — useful for quickly
comparing multiple properties on a similar basis.

### A Starting Point, Not a Full Picture

*ASSUMPTION (for teaching purposes):* Cap rate is a useful first-pass
comparison tool, but it doesn't account for financing details, future
appreciation, or property-specific risk — a fuller treatment comes in
Level 2.

## Worked Example

A property with $24,000 in annual net operating income and a value of
$300,000 has a cap rate of $24,000 ÷ $300,000 = 8%.

## Practice Quiz

1. The basic cap rate formula is:
   A. Rental Income ÷ Down Payment
   B. Net Operating Income ÷ Property Value
   C. Property Value ÷ Mortgage Balance
   D. Total Expenses ÷ Rental Income

2. True or False: Cap rate accounts for mortgage financing details.

3. What is cap rate generally used for?
   A. Calculating property tax
   B. Quickly comparing potential returns across multiple properties
   C. Determining a home inspection's cost
   D. Setting a HOA fee

## Answer Key

1. B
2. False
3. B

## Answers and Explanations

### Question 1

Correct answer: B. Cap Rate = NOI ÷ Property Value.

### Question 2

Correct answer: False. Cap rate is calculated before financing costs are
factored in.

### Question 3

Correct answer: B. It's a quick comparison tool across properties.

## Key Takeaways

- Cap Rate = Net Operating Income ÷ Property Value.
- It estimates potential return as if the property were bought in cash.
- It's a useful starting comparison, not a complete valuation method.
