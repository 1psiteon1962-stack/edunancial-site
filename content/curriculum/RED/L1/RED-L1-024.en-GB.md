# What Is Cash-on-Cash Return?

## Learning Objectives

By the end of this lesson, you should be able to:

- State the cash-on-cash return formula.
- Explain how it differs from cap rate.
- Calculate a basic cash-on-cash return.

## Core Content

### The Formula

Cash-on-Cash Return = Annual Pre-Tax Cash Flow ÷ Total Cash Invested.

Unlike cap rate, which assumes an all-cash purchase, cash-on-cash return
measures the return specifically on the actual cash an investor put into
the deal — including financing.

### How It Differs from Cap Rate

Cap rate ignores financing entirely. Cash-on-cash return specifically
accounts for it, since most investors don't pay all cash — they put down
a portion and finance the rest, and this metric measures return on just
that invested portion.

### Why the Distinction Matters

Two identical properties can have very different cash-on-cash returns
depending on how they're financed, even though their cap rate is the
same — because cash-on-cash return reflects the investor's actual capital
at risk, not the property's total value.

## Worked Example

An investor puts $50,000 down (plus $5,000 in closing costs) on a
property, for $55,000 total cash invested. The property generates $6,600
in annual pre-tax cash flow. Cash-on-Cash Return = $6,600 ÷ $55,000 =
12%.

## Practice Quiz

1. Cash-on-cash return specifically measures return on:
   A. The property's total value
   B. The actual cash the investor put into the deal
   C. The property's net operating income
   D. The local property tax rate

2. True or False: Cash-on-cash return, unlike cap rate, accounts for
   financing.

3. An investor puts $40,000 total cash into a deal and receives $4,800 in
   annual pre-tax cash flow. What is the cash-on-cash return?
   A. 8%
   B. 10%
   C. 12%
   D. 20%

## Answer Key

1. B
2. True
3. C

## Answers and Explanations

### Question 1

Correct answer: B. It measures return on the investor's actual cash
invested.

### Question 2

Correct answer: True. This is the key distinction from cap rate.

### Question 3

Correct answer: C. $4,800 ÷ $40,000 = 12%.

## Key Takeaways

- Cash-on-Cash Return = Annual Pre-Tax Cash Flow ÷ Total Cash Invested.
- It accounts for financing, unlike cap rate.
- Identical properties can have different cash-on-cash returns depending
  on how they're financed.
