# Qu’est-ce que le rendement comptant sur comptant?

## Objectifs d’apprentissage

À la fin de cette leçon, vous devriez pouvoir :

- State the cash-on-cash return formula.
- Explain how it differs from cap rate.
- Calculate a basic cash-on-cash return.

## Contenu principal

### The Formula

Cash-on-Cash Return = Annual Pre-Tax Cash Flow ÷ Total Cash Invested.

Unlike cap rate, which assumes an all-cash purchase, cash-on-cash return
measures the return specifically on the actual cash an investor put into
the deal — including financing.

### How It Differs from Cap Rate

Cap rate ignores financing entirely. Cash-on-cash return specifically
accounts for it, since most investors don't pay all cash — they put down
a portion and finance the rest, and this metric measures return on just
that invested portion.

### Why the Distinction Matters

Two identical propriétés can have very different cash-on-cash returns
depending on how they're financed, even though their cap rate is the
same — because cash-on-cash return reflects the investor's actual capital
at risk, not the propriété's total valeur.

## Exemple pratique

An investor puts $50,000 down (plus $5,000 in clôture costs) on a
propriété, for $55,000 total cash invested. The propriété generates $6,600
in annual pre-impôt flux de trésorerie. Cash-on-Cash Return = $6,600 ÷ $55,000 =
12%.

## Questionnaire pratique

1. Cash-on-cash return specifically measures return on:
   A. The propriété's total valeur
   B. The actual cash the investor put into the deal
   C. The propriété's net operating revenu
   D. The local propriété impôt rate

2. Vrai ou faux: Cash-on-cash return, unlike cap rate, accounts for
   financing.

3. An investor puts $40,000 total cash into a deal and receives $4,800 in
   annual pre-impôt flux de trésorerie. What is the cash-on-cash return?
   A. 8%
   B. 10%
   C. 12%
   D. 20%

## Corrigé

1. B
2. True
3. C

## Réponses et explications

### Question 1

Bonne réponse: B. It measures return on the investor's actual cash
invested.

### Question 2

Bonne réponse: True. This is the key distinction from cap rate.

### Question 3

Bonne réponse: C. $4,800 ÷ $40,000 = 12%.

## Points clés

- Cash-on-Cash Return = Annual Pre-Tax Cash Flow ÷ Total Cash Invested.
- It accounts for financing, unlike cap rate.
- Identical propriétés can have different cash-on-cash returns depending
  on how they're financed.
