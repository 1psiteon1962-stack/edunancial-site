# What Is a Property Manager, and When Do You Need One?

## Learning Objectives

By the end of this lesson, you should be able to:

- Define what a property manager does.
- Explain the basic cost trade-off of hiring one.
- Identify a situation where hiring one might make sense.

## Core Content

### What a Property Manager Does

A property manager handles day-to-day landlord responsibilities on an
owner's behalf — things like collecting rent, coordinating repairs,
screening tenants, and handling tenant communication.

### The Basic Cost Trade-Off

Property managers typically charge a percentage of collected rent (often
in a broad range depending on market and services) as a fee. This is a
genuine trade-off: less hands-on time and effort for the owner, in
exchange for reduced net income.

### When It Starts to Make Sense

Owners with multiple properties, properties far from where they live, or
limited time/interest in hands-on management often find a property
manager's fee worthwhile. A single, nearby rental that an owner enjoys
managing personally may not need one at all — this is a genuine
individual decision, not a universal rule.

## Worked Example

An investor who owns rental properties in three different cities, far
from where they live, hires local property managers in each location
rather than trying to personally handle tenant issues and repairs
remotely.

## Practice Quiz

1. A property manager typically:
   A. Owns the property alongside the investor
   B. Handles day-to-day landlord responsibilities on the owner's behalf
   C. Provides the down payment for a purchase
   D. Sets local property tax rates

2. True or False: Property managers typically work for free, with no
   fee involved.

3. What is one situation where hiring a property manager often makes
   sense?
   A. Owning one nearby property the owner enjoys managing
   B. Owning multiple properties far from where the owner lives
   C. Never owning any rental property
   D. Living directly next door to a single rental

## Answer Key

1. B
2. False
3. B

## Answers and Explanations

### Question 1

Correct answer: B. A property manager handles day-to-day responsibilities
for the owner.

### Question 2

Correct answer: False. Property managers typically charge a fee, often a
percentage of collected rent.

### Question 3

Correct answer: B. Distance and multiple properties often make a
property manager worthwhile.

## Key Takeaways

- A property manager handles day-to-day landlord tasks for a fee.
- The trade-off is reduced net income for less hands-on effort.
- Whether it makes sense depends on the owner's situation, not a
  universal rule.
