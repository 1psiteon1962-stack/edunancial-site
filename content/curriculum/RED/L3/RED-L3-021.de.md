# RED-L3-021: Warum eine HELOC Eigenkapital im Eigenheim in Hebelwirkung verwandelt

## Lernziele
<!-- Core Content -->
Am Ende dieser Lektion kannst du:
- erklären, wie sich eine HELOC von einer Cash-out-Refinanzierung unterscheidet
- erklären, warum die variable, revolvierende Struktur einer HELOC ihr Risikoprofil verändert
- einen häufigen Einsatzzweck für eine HELOC bei Immobilieninvestitionen erkennen

## Hauptinhalt

Eine **HELOC (Home Equity Line of Credit, Kreditlinie auf das Eigenkapital im Eigenheim)** ist eine revolvierende Kreditlinie, die durch das Eigenkapital im Objekt gesichert ist – vom Zweck her ähnlich wie die Cash-out-Refinanzierung aus Lektion 8, aber anders aufgebaut. Statt dein bestehendes Hypothekendarlehen durch einen neuen, höheren Kredit zu ersetzen, liegt eine HELOC als separate Kreditlinie zusätzlich zu deinem bestehenden Hypothekendarlehen. Während eines festgelegten Abrufzeitraums kannst du bis zu einem Limit Geld abrufen, zurückzahlen und erneut abrufen.

Hier ist das „Warum“ hinter der Entscheidung für eine HELOC statt einer Refinanzierung: Sie lässt dein ursprüngliches Hypothekendarlehen (und seinen Zinssatz) unberührt. Das ist sehr wichtig, wenn dieser ursprüngliche Zinssatz günstig ist, wie in der Diskussion über Fiatgeld in Lektion 2 behandelt. Außerdem bietet sie Flexibilität – du zahlst nur Zinsen auf den tatsächlich abgerufenen Betrag, nicht auf die ganze Kreditlinie. Das macht sie nützlich, um eine Renovierung oder eine Anzahlung zu finanzieren, ohne dich von Anfang an auf einen großen Kredit in einer Summe festzulegen.

[VERIFIED FACT] HELOCs haben normalerweise variable Zinssätze. Das bedeutet, dass die Raten steigen können, wenn die Zinsen steigen – das knüpft direkt an das Zinsrisiko aus Lektion 6 an und erfordert eine sorgfältige Planung, wie und wann der Saldo zurückgezahlt wird.

## Durchgerechnetes Beispiel

[ILLUSTRATIVE EXAMPLE] Eine Investorin mit einem günstigen, niedrigen Hypothekendarlehen mit festem Zinssatz auf einer bestehenden Mietimmobilie möchte an $40,000 Eigenkapital kommen, um eine Anzahlung für eine neue Immobilie zu leisten, ohne den ursprünglichen Kredit mit niedrigem Zinssatz anzutasten. Sie eröffnet eine HELOC, statt eine Cash-out-Refinanzierung zu machen, ruft $40,000 für die neue Anzahlung ab und behält den niedrigen Zinssatz ihres ursprünglichen Hypothekendarlehens. Sie zahlt variable Zinsen nur auf die abgerufenen $40,000 und plant, den Betrag mit dem Cashflow aus der neuen Immobilie abzubezahlen.

## Übungsquiz

1. Wie unterscheidet sich eine HELOC im Aufbau von einer Cash-out-Refinanzierung?
2. Warum könnte ein Investor eine HELOC bevorzugen, wenn der Zinssatz seines bestehenden Hypothekendarlehens günstig ist?
3. Welches Risiko bringt die typische Zinsstruktur einer HELOC mit sich?

## Lösungsschlüssel

1. Eine HELOC ist eine separate, revolvierende Kreditlinie zusätzlich zum bestehenden Hypothekendarlehen, während eine Cash-out-Refinanzierung das bestehende Hypothekendarlehen vollständig durch ein neues, höheres ersetzt.
2. Weil eine HELOC das ursprüngliche Hypothekendarlehen mit günstigem Zinssatz unberührt lässt, statt es durch einen neuen Kredit zu ersetzen, der vielleicht einen höheren aktuellen Zinssatz hat.
3. HELOCs haben normalerweise variable Zinssätze, sodass die Raten steigen können, wenn die Zinsen steigen – ähnlich wie das Risiko, das bei Hypothekendarlehen mit variablem Zinssatz besprochen wurde.

## Antworten und Erklärungen

1. Das ist der wichtigste strukturelle Unterschied, um den die Lektion aufgebaut ist.
2. Das knüpft direkt an den Vorteil von Fiatgeld und festem Zinssatz aus Lektion 2 an.
3. Das knüpft direkt an das Zinsrisiko aus Lektion 6 an.

## Das Wichtigste in Kürze
- Eine HELOC ist eine separate, revolvierende Kreditlinie, die durch das Eigenkapital im Eigenheim gesichert ist, und etwas anderes als eine Cash-out-Refinanzierung.
- Sie erhält einen bestehenden günstigen Zinssatz des Hypothekendarlehens und bietet trotzdem Zugang zum Eigenkapital.
- HELOCs haben normalerweise variable Zinssätze und bringen damit dasselbe Zinsrisiko mit sich, das früher in diesem Kurs behandelt wurde.
