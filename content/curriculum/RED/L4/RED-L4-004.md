# NOI Deep Dive: Why Expense Ratios Vary by Property Class

## Learning Objectives
- Recalculate NOI correctly by separating operating expenses from capital expenses and debt service.
- Explain why expense ratios differ between Class A, B, and C properties.
- Identify commonly underestimated expense categories.
- Explain why underestimating expenses inflates a property's apparent value.

## Core Content
Net Operating Income (NOI) is rental income minus operating expenses — but not minus the mortgage payment, and not minus large capital improvements. Getting this line clean matters because NOI drives cap rate, which drives value. VERIFIED FACT: operating expenses typically include property taxes, insurance, property management, repairs and maintenance, utilities not paid by tenants, and reserves for turnover.

Here is the why: expense ratios (expenses as a percentage of income) are not the same across property classes, and treating them as if they are is a common and costly analysis mistake. Class A properties (newer, high-end) typically run 35-45% expense ratios because systems are new and vacancy is low. Class C properties (older, lower-end) often run 50-60% or higher, because older buildings need more repairs, turnover is higher, and management is more labor-intensive per unit. ESTIMATE: these ranges vary by market and should always be verified against actual trailing operating statements, not assumed.

This is why a Class C property advertised with a suspiciously low expense ratio should raise a flag — either the seller is underreporting expenses, deferring maintenance that will hit the new owner, or both.

## Worked Example
ILLUSTRATIVE EXAMPLE: A Class C fourplex shows $40,000 in gross rental income and a seller-reported expense ratio of 30% ($12,000 in expenses), producing an NOI of $28,000. A buyer who investigates the actual trailing twelve months finds real expenses closer to 55% ($22,000) once deferred repairs, higher-than-claimed vacancy, and management fees are included — true NOI is $18,000, not $28,000. At an 8% cap rate, that difference changes the property's justified value by $125,000.

## Practice Quiz
**Q1. Which of the following is correctly included in operating expenses for NOI purposes?**
A) Mortgage principal and interest
B) Property taxes and insurance
C) The down payment
D) A new roof capital replacement

**Q2. Why do Class C properties typically have higher expense ratios than Class A properties?**
A) Class C properties always have lower rents, which lowers expenses
B) Older buildings need more repairs and typically have higher turnover and management intensity
C) Class C properties are exempt from property taxes
D) Expense ratios are set by government regulation based on class

**Q3. A seller reports an unusually low expense ratio for an older Class C property. What should an analyst do?**
A) Accept the number since sellers are required to report accurately
B) Verify against actual trailing operating statements and check for deferred maintenance
C) Automatically reject the deal
D) Assume the ratio applies to all similar properties in the market

**Q4. If actual NOI is lower than a seller's claimed NOI, what happens to the property's justified value at a fixed cap rate?**
A) It increases
B) It stays the same
C) It decreases
D) Cap rate becomes irrelevant

**Q5. Why is it important to separate capital expenditures from operating expenses when calculating NOI?**
A) Capital expenditures are illegal to include in any real estate calculation
B) Mixing them distorts NOI and can misstate a property's true ongoing income
C) Capital expenditures always increase NOI
D) Operating expenses are optional to report

## Answer Key
Q1: B
Q2: B
Q3: B
Q4: C
Q5: B

## Answers and Explanations
**Q1.** Property taxes and insurance are ongoing operating expenses; mortgage payments and large capital replacements are excluded from NOI.

**Q2.** Age, condition, and tenant turnover drive higher relative expenses in Class C properties.

**Q3.** Unusually low expense ratios warrant verification, since underreporting or deferred maintenance can hide true costs.

**Q4.** Value = NOI / cap rate, so a lower true NOI produces a lower justified value at the same cap rate.

**Q5.** NOI is meant to reflect ongoing operating performance; capital expenditures are one-time and belong in a separate analysis.

## Key Takeaways
- NOI equals rental income minus operating expenses, excluding debt service and large capital expenditures.
- Expense ratios differ meaningfully by property class due to age, condition, and turnover.
- Always verify seller-reported expenses against actual trailing statements before trusting NOI.
- Underestimated expenses inflate NOI, which inflates the property's apparent value — a common trap for less experienced buyers.
