# Was ist eine Value Trap? (Warum „billig“ ein Warnsignal sein kann)

## Lernziele

Am Ende dieser Lektion sollten Sie die zentralen Konzepte definieren, ihre praktische Bedeutung erklären und auf ein konkretes Beispiel anwenden können.

## Kerninhalt

### Was eine Value Trap ist

Eine Value Trap ist eine Aktie, die anhand einfacher Kennzahlen wie einem niedrigen KGV billig erscheint, tatsächlich aber aus einem realen und dauerhaften Grund billig ist — wegen rückläufiger Geschäftsfundamentaldaten und nicht nur vorübergehender Fehlbewertung.

### Warum niedriger Preis allein nicht reicht

Ein niedrigerer Aktienkurs oder eine niedrigere Kennzahl als früher bedeutet nicht automatisch ein Schnäppchen. Manchmal spiegelt der niedrigere Preis einen echten anhaltenden Rückgang der Geschäftsaussichten korrekt wider.

### Verbindung zum KGV

Ein niedriges KGV kann Unterbewertung bedeuten — oder die Erwartung sinkender zukünftiger Gewinne widerspiegeln. Die Unterscheidung erfordert eine tiefere Analyse als nur die Kennzahl.

## Durchgerechnetes Beispiel

Der Aktienkurs fällt stark und das KGV sieht im historischen Vergleich attraktiv niedrig aus. Beruht der Rückgang jedoch auf einer echten anhaltenden Verschlechterung des Kerngeschäfts, kann der vermeintliche „Schnäppchenkauf“ eine Value Trap sein.

## Übungsquiz

1. Value Trap: A. echte Unterbewertung B. sieht billig aus, ist aber aus dauerhaftem Grund billig C. Anleihe D. garantierter Gewinn
2. Richtig oder falsch: Ein niedriges KGV bedeutet immer ein Schnäppchen.
3. Warum kann niedriger Preis Problem widerspiegeln? A. nie B. Markt kann sinkende Geschäftsaussichten korrekt einpreisen C. immer Fehler D. passiert nie

## Lösungsschlüssel

1. B
2. Falsch
3. B
