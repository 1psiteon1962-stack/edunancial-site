# What Is Dollar-Weighted vs. Time-Weighted Return? (Why Two People Can Have Different Returns on the "Same" Investment)

## Learning Objectives

By the end of this lesson, you should be able to:

- Define time-weighted return and dollar-weighted return in plain terms.
- Explain why they can produce different numbers for the same fund.
- Recognize why the timing of contributions matters to personal return.

## Core Content

### Time-Weighted Return

Time-weighted return measures how an investment itself performed over a
period, independent of when money was added or withdrawn — it's the
number typically reported by a fund itself.

### Dollar-Weighted Return

Dollar-weighted return measures an individual investor's actual
personal return, which depends heavily on WHEN they added or withdrew
money — the same fund can produce very different dollar-weighted returns
for different investors, based on their personal timing.

### Why They Can Differ

*ILLUSTRATIVE EXAMPLE:* If an investor adds a large sum right before a
downturn, their personal dollar-weighted return will be worse than the
fund's own time-weighted return for that period, even though they're
invested in the exact same fund as someone who invested earlier.

## Worked Example

A fund reports a 10% time-weighted return for the year. An investor who
added a large lump sum right before a brief downturn within that year,
then held through the recovery, might have a personal dollar-weighted
return noticeably different from that reported 10% — same fund, very
different personal experience based on timing.

## Practice Quiz

1. Time-weighted return measures:
   A. An individual investor's personal timing-based return
   B. The investment's own performance, independent of contribution
      timing
   C. Only dividend income
   D. A company's market capitalization

2. True or False: Dollar-weighted return is unaffected by when an
   investor adds or withdraws money.

3. Why can two investors in the same fund have different personal
   returns?
   A. Funds report different numbers to each investor
   B. Their personal dollar-weighted return depends on the timing of
      their contributions
   C. This never actually happens
   D. Only the fund's fees differ between investors

## Answer Key

1. B
2. False
3. B

## Answers and Explanations

### Question 1

Correct answer: B. Time-weighted return measures the fund's own
performance, independent of contribution timing.

### Question 2

Correct answer: False. Dollar-weighted return is specifically shaped by
contribution timing.

### Question 3

Correct answer: B. Personal timing of contributions drives
dollar-weighted return differences.

## Key Takeaways

- Time-weighted return measures the investment's own performance.
- Dollar-weighted return measures an individual's personal, timing
  -dependent return.
- Two investors in the same fund can have genuinely different personal
  returns.
