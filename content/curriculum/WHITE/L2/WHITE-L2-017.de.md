## WHITE-L2-017
### Streuung innerhalb der Wertpapiere

**1. Lernziele**
Am Ende dieser Lektion kannst du:
- die Streuung (Diversifikation) innerhalb einer Anlageklasse von der Vermögensaufteilung über mehrere Klassen unterscheiden.
- den allgemeinen Zweck der Streuung erklären.
- Beispiele für Streuung innerhalb von Aktien und innerhalb von Anleihen nennen.

**2. Kerninhalt**
Während die Vermögensaufteilung (Lektion 16) regelt, wie ein Portfolio auf breite Anlageklassen verteilt wird, geht es bei der Streuung darum, wie ein Portfolio das Risiko innerhalb einer Klasse verteilt – ähnlich wie im Immobilien-Pfad (RED) die Streuung von Immobilien besprochen wurde (RED-L2-038). Bei Aktien kann das bedeuten, viele verschiedene Unternehmen aus unterschiedlichen Branchen (Lektion 24) und Regionen (Lektion 25) zu halten, statt sich stark auf wenige einzelne Unternehmen zu konzentrieren. Bei Anleihen kann das bedeuten, Emittenten unterschiedlicher Bonität, Laufzeit und Art zu halten, statt sich auf einen einzigen Emittenten oder eine einzige Anleihe zu konzentrieren.

Der allgemeine Zweck der Streuung ist, die Auswirkung einer einzelnen schwachen Position auf das Gesamtportfolio zu verringern: Gerät ein Unternehmen oder ein Anleiheemittent in Schwierigkeiten, spürt ein gut gestreutes Portfolio das relativ weniger als ein konzentriertes. Das beseitigt nicht das Risiko des Gesamtmarkts (ein breiter Markteinbruch trifft auch ein gestreutes Portfolio), verringert aber das unternehmens- oder emittentenspezifische Risiko.

**3. Durchgerechnetes Beispiel**
Beim Durchsehen seiner Aktienpositionen stellt Amara fest, dass er zwar zwanzig verschiedene Unternehmen hält, achtzehn davon aber in einer einzigen Branche konzentriert sind. Er erkennt, dass das trotz der scheinbar großen Zahl an Positionen keine ausreichende Streuung ist, und baut sein Portfolio um, sodass sein Aktienengagement über mehrere Branchen verteilt ist. Damit ist er weniger anfällig für einen Abschwung, der speziell diese eine Branche trifft – ohne dass sich die Gesamtzahl seiner Einzelpositionen dafür stark verändern muss.

**4. Übungsquiz**
1. Wie unterscheidet sich laut dieser Lektion die Streuung von der Vermögensaufteilung?
   a) Es sind identische Begriffe
   b) Die Vermögensaufteilung verteilt auf breite Klassen; die Streuung verteilt das Risiko innerhalb einer Klasse
   c) Streuung gilt nur für Immobilien
   d) Vermögensaufteilung gilt nur für Anleihen
2. Was ist der allgemeine Zweck der Streuung?
   a) Einen Gewinn zu garantieren
   b) Die Auswirkung einer einzelnen schwachen Position auf das Gesamtportfolio zu verringern
   c) Jedes Marktrisiko zu beseitigen
   d) Das Risiko auf ein Unternehmen zu konzentrieren
3. Richtig oder falsch: Wer zwanzig Aktien hält, ist automatisch ausreichend gestreut, egal wie stark sie sich auf eine Branche konzentrieren.
4. Welches Problem erkannte Amara in seinem eigenen Portfolio?
   a) Zu wenige Positionen insgesamt
   b) Eine starke Konzentration auf eine einzige Branche trotz scheinbar vieler Positionen
   c) Zu viele Anleihen
   d) Gar keine Aktien

**5. Lösungsschlüssel**
1. b  2. b  3. Falsch  4. b

**6. Antworten und Erklärungen**
1. Die Vermögensaufteilung regelt die Verteilung auf breite Klassen; die Streuung verteilt das Risiko innerhalb einer Klasse.
2. Streuung verringert die relative Auswirkung einer einzelnen schwachen Position auf das Gesamtportfolio.
3. Viele Positionen, die sich auf eine Branche konzentrieren, ergeben keine ausreichende Streuung.
4. Amaras Positionen waren trotz ihrer Zahl stark auf eine einzige Branche konzentriert, was echte Streuung untergrub.

**7. Kernaussagen**
- Streuung verteilt das Risiko innerhalb einer Anlageklasse und unterscheidet sich von der Vermögensaufteilung über breite Klassen.
- Sie verringert das unternehmens- oder emittentenspezifische Risiko, beseitigt aber nicht das Risiko des Gesamtmarkts.
- Viele Positionen garantieren keine Streuung, wenn sie sich auf ähnliche Branchen oder Emittenten konzentrieren.
- Dieses Konzept knüpft an die Diskussion über Streuung im Immobilien-Pfad (RED) an und wird hier auf Wertpapiere angewendet.
