# Edunancial Intelligence Layer — Phase 1

Phase 1 turns the existing AI Learning Network into the foundation for one Edunancial Guide rather than a collection of unrelated bots.

## Principles

1. The committed curriculum remains authoritative and is never rewritten by AI.
2. Approved translations remain stored curriculum; AI conversation is supplemental.
3. Jurisdiction context is a separate layer and uses authoritative-source safeguards.
4. The learner makes financial, investment, tax, and legal decisions. AI teaches concepts and decision frameworks.
5. Membership, progress, and achievements are server-authoritative.
6. AI providers are replaceable behind the Edunancial service boundary.
7. Behavioral events support learning, conversion, retention, and executive analytics without changing curriculum inventory.

## Phase 1 data

The additive Neon migration creates:
- learner_ai_preferences
- learner_events
- ai_learning_interactions

No curriculum table, canonical lesson ID, translation artifact, or publication state is modified.

## Guide actions

The lesson widget provides three first-class actions:
- Explain this
- Give me an example
- Test me

The server classifies the request and injects the matching teaching instruction. Learning-path requests remain educational curriculum recommendations rather than financial recommendations.

## Next phases

Persist learner goals/preferences through authenticated APIs; event instrumentation for registration, lesson start/completion, free-preview completion, membership boundaries, inactivity and cancellation; executive intelligence aggregates; B2B growth/partner agents.
