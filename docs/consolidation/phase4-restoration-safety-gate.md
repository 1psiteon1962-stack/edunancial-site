# Phase 4 restoration safety gate

This work begins only after PR #1011 merges.

Restoration rules:
- preserve every existing learner-visible lesson and translation;
- publish recovered curriculum only through the canonical publication pathway;
- do not re-enable runtime-manifest learner authority or unrestricted recovery publication;
- do not use whole-state legacy replacement as a restoration mechanism;
- validate preservation, integrity, production, integration, and migration safety before merge;
- verify restored material is learner-visible after deployment.

This PR is the first Phase 4 work item and must remain behind #1011 in merge order.
